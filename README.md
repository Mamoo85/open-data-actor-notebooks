# Open-data actor notebooks

Runnable Google Colab / Jupyter notebooks for 29 public [Apify](https://apify.com/transparent_meteorite?fpr=rnmakg) actors that turn open and public data (government filings, jobs, sitemaps, domains, news and more) into pandas DataFrames. Each notebook runs the actor with a tiny sample input via `apify-client`, tabulates the result, and does one small analysis. Overview site: <https://mamoo85.github.io/open-data-actors/>.

## Disclosure

I am the author of these actors. They are pay-per-result; the free plan credit on a new Apify account covers a trial run of each notebook (inputs are deliberately small). You need an Apify API token: in Colab add it as a secret named `APIFY_TOKEN`; elsewhere set the `APIFY_TOKEN` environment variable (or you will be prompted).

## Privacy

Several actors can return emails, phone numbers or person names. In these notebooks every displayed table drops or masks those fields (company-level fields only), and the committed outputs were checked for email addresses and the API token. Actors are not guaranteed to be free of errors on other inputs; check each Store page for coverage and limits.

## Regenerate

`python tools/generate.py <shared-dir>` rebuilds the notebooks from the actor catalog; `tools/run_all.py` executes them (token via `APIFY_TOKEN`).
